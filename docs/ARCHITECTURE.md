## 引擎详解

|------|-----|
| 数据源 | `tv.cctv.com/lm/xwlb/day/YYYYMMDD.shtml` |

## 去重流水线

```
原始采集 (350+条)
    │
    ▼
阶段1: 精确去重 (URL/MD5/标题完全一致)
    │ → 去除约30%重复
    ▼
阶段2: 语义去重 (Embedding相似度>0.85)
    │ → 再去除约20%近似重复
    ▼
阶段3: AI核验 (LLM判断是否同一事件)
    │ → 避免误合并
    ▼
阶段4: 事件聚类 (HDBSCAN自动分簇)
    │ → 生成事件簇
    ▼
最终呈现 (~150-200条独立新闻)
```

## 多模型路由

| 任务 | 模型 | 原因 |
|------|------|------|
| 新闻摘要 | 主力模型 | 需要高质量总结 |
| 情感分析 | 备用模型 | 简单任务，省成本 |
| 去重判断 | 备用模型 | 简单的是/否判断 |
| 聚类验证 | 备用模型 | 需要速度优先 |
| 报告生成 | 主力模型 | 需要深度分析 |
| 对话回复 | 主力模型 | 需要理解上下文 |

## 输出格式

### Markdown (默认)
- 用于聊天对话直接展示
- 带完整格式和链接

### HTML (邮件/分享)
- 卡片式排版
- 适合邮件和社交媒体分享

### 图片 (社交媒体)
- 生成热点新闻卡片
- 使用Pillow生成

### PDF (归档)
- LaTeX/WeasyPrint生成
- 含目录和图表

### RSS (订阅)
- 标准RSS 2.0格式
- 可订阅日报Feed

## 安全设计

- 所有API调用通过HTTPS
- 凭据存储在本地`.git-credentials`，不上传
- `.gitignore`排除敏感文件
- 支持Token过期和轮换

## 性能

| 指标 | 值 |
|------|-----|
| 单次采集时间 | ~30-60秒 (并行) |
| 去重处理时间 | ~5-10秒 |
| 报告生成时间 | ~10-20秒 |
| 总耗时 | ~60-90秒 |
| 内存占用 | < 512MB |

## 扩展性

- 新增数据源: 在`SKILL.md`中添加引擎配置
- 新增输出格式: 在输出层添加模板
- 新增情感模型: 在情感层添加路由
- 新增去重算法: 在去重流水线添加阶段
